The steps above already show every substitution with real numbers. More detail on where each default value comes from:

The default batch size, 100.6 million tokens/step, is the figure reported in the DeepSeek V4.1 Flash technical report. The default peak compute, 989.5 TFLOP/s, is NVIDIA's published H100 SXM BF16 Tensor Core figure of 1,979 TFLOP/s "with sparsity," halved to the dense (non-sparse) rate — the standard convention, since the product page does not list a dense figure directly. GPU count (2,048) and training step time are not published anywhere and are explicitly hypothetical teaching assumptions. See References below for links.

For a Mixture-of-Experts model like DeepSeek V4.1 Flash, only a small fraction of stored parameters are actually used by any one token — applying the common "6 × total parameters" rule of thumb directly would overstate real training cost. This example deliberately keeps that complication out of the headline number and uses clearly hypothetical FLOPs/token instead; see README.md for a worked MoE active-vs-total comparison.
