Full 的 Index Key 从未旋转的 Compressor latent 生成；Indexer Query 来自本层低秩 Q，经独立投影与 RoPE，Head Weights 来自本层 X。随后 Global latent 才做 RoPE → FP4 → 写缓存。Reindex 保留 KV / Index Keys，重算 Indexer Query、Head Weights、评分与 Top-K；Reuse 直接读取上游索引。L20 另建立分层候选池，后续 Reindex 受候选 mask 限制。

同一 latent 同时作为 K 与 V；RoPE 处理尾部 64 维。Local 写 FP8 环形缓存；Global 写 FP4 缓存。Attention 后逆 RoPE，输出按 8 组重排，FP8 量化 / 反量化后执行分组 W_OA，再执行 W_OB。图示为 B=1、当前一个 token、逻辑未分片维度；S 随历史增长，Top-512 为上限。ratio=2 未完成一组时不追加 Global 条目。
